# wb3-tts-importer
A repository to faciliate creation and playtesting of the game Wizard Battle 3 on Table Top Simulator.

Operation:
Paste your decklist into decklist_here.txt
Run program
I will add a command to refresh the CSV data.
It will generate 2 images, assuming you provided an Extra Deck

A decklist formatting example is at example_decklist.txt, formatting below.

Example Name
Main Deck:
1 Paranoid Puppy

Extra Deck:
