# wb3-importer
A repository to faciliate creation and playtesting of the game Wizard Battle 3.

To run the app, download the most recent version folder in output. Windows only so far.

Operation:
1. Paste your decklist into decklist_here.txt
2. Double check to make sure this is in the correct output folder! The place you shouldn't paste it says DON'T PASTE HERE
2. Run program (the .exe file)
3. Update card database if you haven't within done so within the past few hours.
3. It will generate 3 images, assuming you provided an Extra Deck

A decklist formatting example is in example_decklist.txt,  and a short one is below

Example_Deck_Name\
Main Deck:\
2 Find a Way\
2 Bloody Search\
3 Badass Name\
3 Bloodletter\
\
Extra Deck:\
3 Ritual Fellow\
