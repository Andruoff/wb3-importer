# wb3-tts-importer
A repository to faciliate creation and playtesting of the game Wizard Battle 3 on Tabletop Simulator.

To run the app, download the folder. Windows only so far.

Operation:
1. Paste your decklist into decklist_here.txt
2. Run program
3. (Optional) Update card database.
3. It will generate 2 images, assuming you provided an Extra Deck

A decklist formatting example is in example_decklist.txt.
